# nixos-installer

A lightweight, friendly NixOS installer. Boot the ISO, answer a few questions, and get a plain NixOS. It can then hand over to your dotfiles.

It owns the machine layer: partitions, encryption, swap, hibernate, hardware configuration, bootloader, hostname and timezone. It writes these to `/etc/nixos` and knows nothing about your personal setup. Sizes come from what it detects, and every suggestion can be edited.

**It erases the disk you choose.** Dual boot isn't supported. Nothing is changed until you type the disk's name at the final confirmation.

## Build and flash

```bash
nix build .#iso
sudo dd if=result/iso/*.iso of=/dev/<usb-stick> bs=4M status=progress conv=fsync
```

Set your default dotfiles repo and branch in `settings.nix`. You can also change them at install time, or leave the repo empty to stop at plain NixOS. Disable Secure Boot in the firmware before booting.

## What it writes

| File in `/etc/nixos` | Purpose |
|---|---|
| `hardware-configuration.nix` | Generated by `nixos-generate-config`: drivers, disks, CPU architecture |
| `machine.nix` | Your answers, and the build limits calculated from RAM and CPU threads |
| `configuration.nix` | Imports those two and adds a user, network, git and flakes |
| `dotfiles-source`, `first-boot.sh` | Only if you chose a dotfiles repo |

## Dotfiles contract

A dotfiles repo needs to be readable without logging in and to provide `nixos/bootstrap.sh`. On the first login on tty1, the system clones the repo to `~/dotfiles` and runs that script. If it fails, you keep a working NixOS and can retry with `bash /etc/nixos/first-boot.sh`.

To use the machine layer from a flake, import `/etc/nixos/hardware-configuration.nix` and `/etc/nixos/machine.nix`, and rebuild with `--impure`.

## Tests

```bash
bash tests/test-install.sh                # unit tests, no disks involved
VM_TEST_WORK=/some/dir tests/vm-test.sh   # full installs in throwaway QEMU VMs
```

The VM tests write only to qcow2 images in the work directory. They download a few GiB per install and use 2.5 GiB of RAM per VM.
